# Better Burnside — notes

## 2026-07-18 — project born (Claude cloud session, "Portland Policy" project)
Seattle trip → downtown lessons research → W Burnside identified as the orphaned-corridor
opportunity. Key facts established (all cited in the Claude project docs):

- **Bridge:** EQRB closure postponed indefinitely (Oct 20, 2025 county release; $1.6–1.8B,
  ~$7M of ~$740M federal secured). Full-closure approach (no temp bridge) stands. 60% design
  targeted summer 2026. The PSU plan's 2028–2033 window is superseded → reframed the campaign
  as "prep years now, window when funded."
- **Coalition seed:** Better Block PSU + DNA (Stickler) + Pearl (Sweat) + Old Town (O'Meara),
  Better Block PDX (Hashagen). Missing: stadium end (GHFL, NWDA, Timbers, MAC, Fred Meyer...).
- **Vacancy epicenter:** stadium blocks — Matador dark since 2014; 1972 W Burnside whole
  building + lot empty (my field observation); HunnyMilk closing; Fred Meyer at risk.
  No agency counts storefronts west of ~SW 10th → our inventory fills a real data hole.
- **Transit:** eastbound BAT lanes (3rd→8th building, Broadway→2nd funded) + 2019 bridge bus
  lane; lines 12/19/20.

Site prototype built (Astro one-pager, data-driven from `src/data/site.ts`), delivered as
zip + rendered artifact. Deep-research report: 101 agents, 22 confirmed claims, 3 refuted —
including our own earlier "closure starts 2026-27" assumption. Good reminder to re-verify
timeline claims before public launch.
