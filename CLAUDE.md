# Hub — agent orientation

This is GZ's markdown command center. Code lives in each project's repo; this is
the brain: status, todos, notes, research. Start with `README.md` (project index).

For anything related to Portland civic work (Better Burnside, Rose Light civic
features, downtown/parks research): read `projects/civic-stack/readme.md` FIRST —
it maps the assets, current next actions, and operating rules. Deep research lives
in `projects/civic-stack/research/`. The governing convention is
`docs/conventions/context-sync.md`: this hub is the single source of truth; keep
it updated at the end of any session that changes state (dated notes.md entry,
todo checkboxes, readme Updated line).

Per-project files follow the four-file pattern: readme (status+links), todo
(tasks, source of truth), notes (dated journal), ideas (backlog). Root todo.md is
a hand-curated rollup — don't auto-edit it.
